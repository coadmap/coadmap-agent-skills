# 03. 作業中の意思決定をタスクコメントに記録

タスク遂行中、**ユーザーとの対話で確定した意思決定・仕様の詳細化・前提の変更**が発生する**都度**、Coadmap タスクのコメントとして残す。後から経緯を追えるようにするのが目的。

## いつ投稿するか

- 仕様の曖昧さが対話で解消されたとき
- 実装方針・採用/不採用の技術選定が決まったとき
- スコープの増減・前提条件の変更が合意されたとき
- 想定外の事象への対処方針が決まったとき

雑談や中間の試行錯誤は対象外。**「決定」したことだけ**を簡潔に残す。

## 投稿方法(MCP)

```
create_coadmap_task_comment(
  taskId  = "<raw UUID または global ID>",   # 00 で取得済みのものを使う
  content = "<Markdown 本文>"
)
```

- `taskId` は displayId ではなく raw UUID / global ID。displayId しか無い場合は 00 で取得した UUID を使う。
- 投稿は外向き操作なので、投稿前に本文をユーザーに見せて承認を取る。

## コメントのテンプレート

```markdown
## 意思決定: <一言タイトル>

**背景**: <なぜこの判断に至ったか>

**決定**: <何を決めたか>

**反映先**: <該当 PR / ファイル / 後続タスク など>
```

## 注意

- **秘匿情報(トークン・API キー・パスワード等)はコメントに含めない**。
- 誤投稿した場合は Coadmap UI から TaskComment を削除して取り消せる。
