### コンポーネント（`ProductDomain`）

プロダクトヒエラルキー上で、機能を分類するためのまとまり。

## 何か
- 機能のカテゴリ・ドメイン・サブシステム単位、またはプラットフォーム／ページ単位。
- プロダクトの直下に並ぶ。
- 2〜3 階層までに収めるのが推奨。
- サブコンポーネントも使える。

## 組み方の 2 パターン

### Case 1: ドメインごとに区切る（ドメイン駆動）
ドメイン／サブドメインをコンポーネントとして扱う。

```
コンポーネント:認証
  └─ 機能:ログイン
  └─ 機能:権限管理
コンポーネント:決済
  └─ 機能:カート
```

### Case 2: プラットフォーム／ページごとに区切る（UI 駆動）
プラットフォームやページ単位でコンポーネントを切る。

```
コンポーネント:Web
  └─ 機能:ホーム画面
  └─ 機能:商品一覧画面
コンポーネント:Mobile
  └─ 機能:商品詳細画面
```
