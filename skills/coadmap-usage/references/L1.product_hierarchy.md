### プロダクトヒエラルキー

組織が**「何を」作るかを明確にするための階層構造**。
プロダクトに紐づく 1 本のヒエラルキー（オブジェクティブヒエラルキーとは独立）。

## 構造

```
プロダクト
  └─ コンポーネント
      └─ サブコンポーネント（コンポーネントは 2〜3 階層推奨）
          └─ 機能
              └─ サブ機能（機能は 2 階層まで強制）
```

実装済みの機能・機能アイディアを問わず、**すべての機能をここに整理する**。

## 目標カラム

プロダクトヒエラルキーには「目標カラム」を追加できる。
複数の目標を選んで Switch で並べ、各機能行に対して目標を引き当てる UI。

```
プロダクトヒエラルキー                目標カラム
├─ コンポーネント:認証
│   ├─ 機能:ログイン       ────→     目標:ユーザー獲得
│   └─ 機能:権限管理       ────→     目標:エンタープライズ対応
└─ コンポーネント:決済
    └─ 機能:カート         ────→     目標:売上向上
```

これにより「機能がどの目標達成に寄与するか」を機能ごとに引き当てる。

目標 ↔ 機能の紐付けは、ここに加えて**機能の詳細サイドバー**でも行える（→ [機能](L1.product_feature.md)）。
