### リスク台帳（`RiskRegisterItem`）

プロジェクトで見つかったリスクを 1 件ずつ載せ、状態・根拠・アクションを継続して管理する台帳。

## 何か
- 台帳の 1 項目は、1 つのプロジェクト（`Workspace`）に属する。
- 重要度は 3 段。

| 値 | 意味 |
|---|---|
| 観察（`OBSERVATION`） | 低緊急度。台帳で再発監視 |
| 注意（`CAUTION`） |  |
| 重要（`IMPORTANT`） | PM確認が必要 |

- 起票元は 3 種類。

| 値 | 意味 |
|---|---|
| Yataの深掘り生成（`YATA`） |  |
| BE決定論検知器（`DETECTOR`） |  |
| 手動起票（`MANUAL`） |  |

## 状態
| 値 | 意味 |
|---|---|
| 未対応（`UNADDRESSED`） | まだ誰も手を付けていない |
| 対応中（`IN_PROGRESS`） | 対応を進めている |
| 解決済み（`RESOLVED`） | 解消した |
| 受容（`ACCEPTED`） | 人が許容すると判断した。再発したときだけ戻る |
| 抑制（`SUPPRESSED`） | 人が一旦ミュート・後回しにした。再発したときだけ戻る |

- 受容と抑制は、人が判断した結果。台帳に受容・抑制で載っているリスクを、新しく見つけたリスクとして扱わない。

## 根拠とアクション
- 根拠（`evidences`）は、タスク・機能・ノートへの参照と、なぜ根拠になるかの補足。
- アクション（`actions`）は、対応のためのチェックリスト。

## 画面
- リスク台帳はプロジェクトのリスク台帳タブで見る。リスク 1 件を開く詳細画面は無い。
- リスク台帳はプラン機能で、対象外のプランの会社には表示されない。

## 出典としてのリンク先
- リスクへのリンク先は、そのプロジェクトのリスク台帳タブ。
