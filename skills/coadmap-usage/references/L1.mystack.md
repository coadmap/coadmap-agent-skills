### マイスタック（`MyStackItem`）

ユーザーが Task / Note / 各 PdmSubject / 自由入力テキストを横断的に積んで管理する個人スタック。ユーザーには一貫して **「マイスタック」** と呼ぶ。

## 何か
- 種類の違うリソースを `position` 順に1列で並べる、個人用の作業棚。
- 1件 = `MyStackItem`。`stackable`（Task/Note/Product 等）への参照、または自由入力テキスト。
- アクションは **積む** と **消す** の 2 つだけ。「片付いた」は消すことで表す（チェック等の第3の状態は持たない）。30件の上限があるため、片付いたものを残す状態を作ると実効容量が減っていく。
